How to add new tracks on GitHub Pages

To add song #7, create a folder named tracks/7/ (or root 7/) in your GitHub repository and upload three files:

  • a.mp3 — Your master / finished mix
  • b.mp3 — Rough mix / raw multitrack comparison
  • info.json — Track metadata template (below)
{
  "artist": "Artist Name",
  "title": "Song Title",
  "genre": "Rock / Pop / Indie",
  "bpm": 120,
  "key": "A min",
  "duration": "03:45",
  "date": "2026.10",
  "version": "Roland K Master",
  "notes": "Mixing details, vocal chain, and mastering headroom notes."
}

Tip: You can also use plain text (info.txt) with simple lines: artist: Name, title: Song, bpm: 120.
